# Database Technologies (PCSMJ114) Lab Assignments

Complete implementations for M.Sc. Computer Science Semester I Database Technologies laboratory course.

## Structure
- **MongoDB/**
  - `Assignment_1_Movie_DB.js`: Schema creation, insertMany, filter updates, and targeted deletions.
  - `Assignment_2_Company_DB.js`: Batch transactions, embedded document updates, and regex queries.
  - `Assignment_3_Aggregate_MapReduce.js`: Aggregation pipelines, cursor traversals, lookups, and MapReduce.
- **Neo4j/**
  - `Assignment_4_Graph_Creation.cypher`: Node and relationship definitions across Library, Song, Employee, Movie, and Social domains.
  - `Assignment_5_Simple_Queries.cypher`: Single-hop graph queries, property mutators, and direct pattern matching.
  - `Assignment_6_Complex_Queries.cypher`: Multi-hop traversals, negative pattern filtering, and complex graph analytics.
