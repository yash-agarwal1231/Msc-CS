# Assignment 3 - Strings I

Principles of Programming Languages (PPL)
M.Sc. Computer Science - Semester I
Academic Year 2026-27

## Programs

### Set A
1. Q1 - Count uppercase letters, convert the string to lowercase, and display it.
2. Q2 - Read a character and count its occurrences in a given string.
3. Q3 - Remove a character at a given position after validating the position.
4. Q4 - Check whether a string is a palindrome using if/else and pattern matching.

### Set B - Practice Questions
5. Q5 - Count vowels and consonants in a user-given string.
6. Q6 - Replace every space character with a hyphen.

All programs are written in Scala with a simple, properly indented practical-exam style.
