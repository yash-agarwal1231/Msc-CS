# Assignment 4 - Strings II

Principles of Programming Languages (PPL)
M.Sc. Computer Science - Semester I
Academic Year 2026-27

## Programs

### Set A
1. Q1 - Check whether two given strings are rotations of each other.
2. Q2 - Create an array of strings and display elements containing a target string.
3. Q3 - Reverse every word in a given string.
4. Q4 - Append two strings after making their lengths equal by removing characters from the beginning of the longer string.

### Set B - Practice Questions
5. Q5 - Find all duplicate characters and their counts in a given string.
6. Q6 - Remove all occurrences of the second string from the first string.

All programs are written in Scala with a simple, properly indented practical-exam style.
