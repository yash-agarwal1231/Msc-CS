# Assignment 5 - Arrays and Lists

## Principles of Programming Languages

M.Sc. Computer Science - Semester I  
Academic Year 2026-27

---

## Set A

### Q1 - List Add and Remove
Create a List, add 3 new elements, remove all even numbers,
and display the final List.

### Q2 - Remove Element from List
Remove a specific element entered by the user from a List
of integers by value and by index position.

### Q3 - Array Maximum and Minimum
Find the maximum and minimum elements in an integer Array.

### Q4 - Separate Even and Odd
Separate even and odd numbers from a given Array
into two separate Lists.

---

## Set B - Practice Questions

### Q5 - Array Search
Search for a specific element in an Array and display
its index position if present.

### Q6 - Merge Lists and Remove Duplicates
Merge two Lists, add a new element to the merged List,
and remove all duplicate elements.

---

All programs are written in Scala with a simple,
properly indented practical-exam style.
